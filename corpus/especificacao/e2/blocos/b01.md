#### E.2.0 Base comum: classes de token, relato e posição

**Classes de token** (`fe:scanner/token.dart`). `token.kind == IDENTIFIER_TOKEN` só para
identificador que não é palavra-chave. Toda palavra-chave é `KeywordToken`, com um estilo:

| estilo | `isIdentifier` | palavras (3.6.2) |
|---|---|---|
| `reserved` | não | `assert break case catch class const continue default do else enum extends false final finally for if in is new null rethrow return super switch this throw true try var void while with` |
| `builtIn` | sim | `abstract as augment covariant deferred dynamic export extension external factory Function get implements import interface late library mixin operator part required set static typedef` |
| `pseudo` | sim | `async await base hide inout native of on out patch sealed show source sync when yield` |

`KeywordToken.isIdentifier = isPseudo || isBuiltIn` (`token.dart:488`); `isKeywordOrIdentifier` é
verdadeiro para toda palavra-chave (`:494`). Marcas extras: `isModifier` = `abstract augment
covariant external late required static const final var`; `isTopLevelKeyword` = `class enum export
extension import library mixin part typedef`. Dependem da configuração do scanner
(`an:dart/scanner/scanner.dart:198-207`, `fe:scanner/abstract_scanner.dart:1747-1756`): `augment` só
é palavra-chave com `Feature.macros`; `late`/`required` só com `non_nullable`; `extension` só com
`extension_methods`; `>>>`/`>>>=` só são um token com `triple_shift` (`:1212`).

**Predicados de recuperação** (todos dão verdadeiro no EOF, por `isOneOfOrEof`,
`fe:parser/util.dart:88`):
- `looksLikeStatementStart(t)` (`fe:parser/identifier_context.dart:391`): `@ assert break continue do
  else final for if return switch try var void while`.
- `looksLikeStartOfNextTopLevelDeclaration(t)` (`fe:parser/identifier_context_impl.dart:1330`):
  `t.isTopLevelKeyword` ou `const get final set var void`.
- `looksLikeStartOfNextClassMember(t)` (`:1327`): `t.isModifier` ou `@ get set void`.
- `looksLikeExpressionStart(t)` (`identifier_context.dart:333`, sem a cláusula de EOF): identificador;
  palavra-chave que não é `looksLikeStatementStart`; literal numérico ou string;
  `# { ( [ [] < ! - ~ ++ --`.
- `okNextValueInFormalParameter` (`identifier_context.dart:400`): `= : , ) ] }`.

**Relato.** `reportRecoverableError(token, msg)` e `reportRecoverableErrorWithToken(token, modelo)`
(`fe:parser/parser_impl.dart:9429`, `:9445`) trocam o token por `findNonZeroLengthToken(token)`
(`fe:parser/util.dart:62`: avança enquanto o token é sintético de comprimento 0 e não é EOF) e
chamam `listener.handleRecoverableError(msg, token, token)`. No AstBuilder

**Duplicatas.** O ouvinte de erros é um conjunto (`RecordingErrorListener._errors`,
